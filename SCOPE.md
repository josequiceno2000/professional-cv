# Scope

## Main Goal
- [ ] Create a single-page CV (Curriculum Vitae) using only HTML and CSS.

## Sub Goals
- [ ] **Semantic HTML**: use appropriate HTML tags
- [ ] **SEO Meta Tags**: include essential meta tags for SEO
- [ ] **Open Graph (OG Tags)**: add OG tags for better social media sharing.
- [ ] **Favicon**: add favicon to CV page
- [ ] **Layout**: add all appropriate sections
  - [ ] *Name*
  - [ ] *Contact and Title*
  - [ ] *Skills*
  - [ ] *Education*
  - [ ] *Experience*
  - [ ] *Links*

## Procedure
- [ ] Create mood board 
  - [ ] Create project in Figma
  - [ ] Collect inspiration from Pinterest
  - [ ] Collect inspiration from Google
  - [ ] Collect inspiration from Dribble
  - [ ] Select top 2 inspirations
  - [ ] Organize everything in mood board
- [ ] Make design elements
  - [ ] Select singular font for document
  - [ ] Create style for Name
  - [ ] Create style for Section Title
  - [ ] Create style for Section Subtitle
  - [ ] Create style for Section content
  - [ ] Create unique styles as necessary
- [ ] Create design on Figma
  - [ ] Create frame in Figma
  - [ ] Add proper bleed and margin
  - [ ] Organize all elements
  - [ ] Place design in a website page frame
  - [ ] Export 
- [ ] Code page
